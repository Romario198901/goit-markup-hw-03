# Web Studio Landing Page

A responsive HTML and CSS landing page for a fictional digital studio called Web Studio. This project includes a hero section, features, team section, and portfolio showcase.

## Project structure

- `index.html` — main page markup
- `css/styles.css` — page styling
- `images/` — project images used in the portfolio and team sections
- `.gitignore` — ignored files for Git
- `prettierc.json` — code formatting configuration

## Features

- Responsive landing page layout
- Navigation and contact links
- Hero section with call-to-action button
- Features / advantages cards
- Team section with member cards and optimized images
- Portfolio gallery
- Simple footer

## How to use

1. Open `index.html` in your browser.
2. Edit the HTML or CSS files to customize text, colors, layout, or images.
3. Use a local development server if preferred for a better preview experience.

## Notes

- The page uses Google Fonts (`Raleway` and `Roboto`).
- `modern-normalize` is loaded from a CDN to normalize browser styles.
- Images are stored in the `images/` folder and referenced from `index.html`.

## Recommended workflow

- Use a code editor like VS Code.
- Keep styles in `css/styles.css` and markup in `index.html`.
- Preview changes in the browser frequently.
